# 냉장고 식단 에이전트 (Claude API)

냉장고 재료로 한 끼 메뉴를 찾고, 인원에 맞춰 필요량 · 부족량을 계산하는 에이전트입니다.
Claude가 tool use로 필요한 도구만 고르고, 수량 계산은 코드(`tools.py`)가 합니다.
모든 자료는 교육용 가상 자료이며, 재료 제외는 선호 반영일 뿐 알레르기 안전을 보장하지 않습니다.

## 실행

```bash
pip install -r requirements.txt
copy .env.example .env      # .env를 열어 ANTHROPIC_API_KEY=... 입력
streamlit run app.py
```

- 모델: 기본 `claude-sonnet-5-5` (`.env`의 `CLAUDE_MODEL`로 변경 가능)
- 키를 바꾸거나 비운 뒤에는 브라우저를 새로고침하면 반영됩니다. 키가 없으면 질문 입력창이 잠기고 안내만 나옵니다.
- 코드 검산(API 키 불필요): `python test_core.py`

## 구성

| 파일 | 역할 |
|---|---|
| `app.py` | Streamlit 화면: 파일 교체, 재료·메뉴 표, 채팅, 후보 선택, 계산 표, 도구 실행 기록, 새 대화, 설정·모의 시험 |
| `agent.py` | Claude tool use 루프, 호출 상한, 시간 초과·모델 실패 구분, 실패 시 대화 롤백 |
| `tools.py` | 도구 5개(재고 조회 · 메뉴 목록 · 후보 검색 · 레시피 상세 · 인원별 계산)와 계산 로직 |
| `data_loader.py` | 냉장고 CSV · 레시피 JSON 검사(중복ID · 음수 · 단위 · 기준인원 · JSON 손상) |
| `test_core.py` | 과제안내서의 숫자 기대값 검산 |
| `data/` | 원본 자료(수정하지 않음) |

## 장보기 기능 (추가)

- "김치찌개랑 두부부침 먹고 싶어, 두 명이야"처럼 먹고 싶은 메뉴를 말하면 `plan_shopping` 도구가 여러 메뉴를 **합산**해 재료별 필요 · 보유 · 부족과 장보기 목록을 만듭니다(예: 두부 450g 필요 / 300g 보유 / 150g 부족).
- 사이드바 `🛒 장보기 목록`에 가장 최근 계산의 부족 재료가 체크박스로 나오며 CSV로 내려받을 수 있습니다.
- 등록되지 않은 메뉴(예: 토마토 파스타, 카레)도 됩니다. 이때 재료량은 **AI가 일반적인 양으로 추정**한 값이라 화면에 `AI 추정`으로 따로 표시하고, 냉장고와의 비교 · 합산 · 부족량 계산은 코드가 합니다. 등록 메뉴와 섞어서 한 번에 합산할 수도 있습니다.
- 단위가 다른 재료는 계산을 보류합니다. AI 추정 수량은 등록된 레시피가 아니므로 참고용입니다.

## 동작 원칙

- 필요량 = 기준량 × 인원 ÷ 기준인원, 부족량 = max(필요 − 보유, 0). 분수로 계산해 4.5개 같은 값을 반올림하지 않습니다.
- 화면의 표 · 후보 · 조리 순서는 도구 반환값을 그대로 그립니다(모델 문장에서 숫자를 가져오지 않음).
- 냉장고에 없는 재료는 '미등록, 보유 0으로 비교', 단위가 다르면 그 재료만 '계산 보류'입니다.
- 데이터 오류가 있으면 재고를 비우거나 0으로 바꾸지 않고 오류 위치를 보여 주며 판단 · 계산을 멈춥니다.
- 추천 · 계산은 조회일 뿐이며 재고(원본 파일)를 바꾸지 않습니다.
- 실행 기록에는 실제로 실행한 도구 호출만 남습니다(이름 · 인자 · 성공/실패 · 반환 요약).

## 시험 방법

- 제한 시간 시험(C5-4/5): 사이드바 `설정 · 모의 시험`에서 응답 제한 시간을 0.01초로 바꾸고 질문 → `시험용 실패` 표시와 `다시 시도`. 원래 값(60)으로 되돌려 `다시 시도`.
- 호출 상한 · 도구 실패(C5-8): 같은 곳에서 도구 호출 상한을 1~2로 낮춰 "당근밥 두 명 분량 계산해줘" 등을 묻거나, `첫 도구 호출을 일부러 실패시키기`를 켭니다. 기록에 `모의 시험`으로 표시됩니다.
- API 키 시험(C5-6/7): `.env`의 키를 비우고 새로고침 → 안내만 나오고 입력창 잠김. 키를 다시 넣고 새로고침 → 정상.
